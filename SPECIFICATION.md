# ExamApp-Team Specification

## Project Overview
ExamApp-Team is a React client application for managing exams. The project is built by a team using GitHub, Issues, Kanban, branches, Pull Requests, and deployment.

## Main Users

### Teacher
The teacher can:
- View all exams
- View dashboard statistics
- Create and manage exams
- See exam status, date, class, duration, and number of questions

### Student
The student can:
- Login to the system
- Enter an exam ID
- Search for an exam
- View exam details
- Start an exam

## Main Features
- React client application
- Bootstrap design
- Teacher dashboard
- Student portal
- Login screen
- Mock API data
- GitHub Issues workflow
- Kanban project board
- Feature branches
- Pull Requests
- Deployment

## Technologies
- React
- Vite
- JavaScript
- Bootstrap
- Git
- GitHub
- Render

## Team Work
The project is managed by two collaborators using GitHub. Each task is tracked by an Issue, developed in a feature branch, reviewed through a Pull Request, and moved on the Kanban board.

## Goal
The goal of this project is to practice building a React client application and working with a professional GitHub workflow.
