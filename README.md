# ExamApp-Team

A React exam management client application built with GitHub Issues, Kanban board, feature branches, Pull Requests, and Render deployment.

## Live Demo

https://examapp-team.onrender.com

## Main Features

- Login screen
- Teacher dashboard
- Student portal
- Exam list
- Mock exam data
- Bootstrap design

## Technologies

- React
- Vite
- JavaScript
- Bootstrap
- Git
- GitHub
- Render
